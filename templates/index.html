⚡ Opción A: Envío Automático en 1 Clic (API Directa)

  1. Ve a Supabase Access Tokens ↗, crea un token (empieza por sbp_...) y pégalo abajo.
  2. Copia el Project ID (Reference ID) de tu proyecto en Project Settings → General (20 letras, ej. abcdefghijklmnopqrst).
  3. Pulsa en Subir a Supabase Ahora (no requiere instalar Supabase CLI).

⚡ Opción A: Envío Automático en 1 Clic (API Cloudflare v4)

  1. Ve a Cloudflare API Tokens ↗ → Create Token → usa la plantilla Edit Cloudflare Workers.
  2. Copia tu Account ID (está en la barra derecha de Workers & Pages en Cloudflare) y el nombre de tu Worker.
  3. Pulsa en Subir a Cloudflare Ahora.
